# 문자(SMS) 자동발송 검토

2026-09-03 · GIA 운영 시스템(gia-ops-web) 기준

---

## 요약

**됩니다. 그리고 카카오톡보다 훨씬 빨리 시작할 수 있습니다.**

| | 문자 | 알림톡(카카오) |
|---|---|---|
| 문구 사전 심사 | **없음** — 그때그때 다른 내용 가능 | 템플릿마다 2~5영업일 심사 |
| 준비 기간 | **1~2일** (발신번호 등록) | 2~3주 (채널·프로필·템플릿) |
| 건당 비용 | 약 10~20원 (90자 이내) | 약 8~13원 |
| 도달 | 통신사 망. 스팸 차단만 아니면 다 감 | 카톡 미사용자에게는 안 감 |
| 받는 쪽 부담 | 알림이 잘 뜸 | 카톡 알림에 묻히기도 함 |

**심사가 없다는 점이 결정적입니다.** 우리가 보내려는 것들은 대부분
"○○ 학생 9/21~23 결석으로 접수했습니다" 처럼 **매번 내용이 다릅니다.**
알림톡이면 이런 걸 템플릿으로 미리 다 등록해야 합니다.

---

## 1. 어떻게 하는가

### 필요한 것

1. **발신번호 사전등록** — 법(전기통신사업법)으로 정해진 절차입니다. 학교 대표번호를
   통신서비스 이용증명원 등으로 등록합니다. 하루면 됩니다.
2. **발송 대행사 계약** — 솔라피·알리고·NHN Cloud·가비아 등. 월 기본료 없이
   **보낸 만큼만** 냅니다. API 연동 비용도 없습니다.
3. **우리 앱에 발송 함수** — 사실상 HTTP 요청 한 번입니다.

### 우리 쪽 개발

| 무엇 | 규모 |
|---|---|
| 발송 함수 + 발송 기록 표(`sms_logs`) | 1일 |
| 문구 만드는 자리(사건별) | 1일 |
| 실패 재시도 · 발송 결과 웹훅 받기 | 0.5일 |
| 관리 화면(무엇이 언제 누구에게 나갔나) | 1일 |

**합쳐 3~4일.** 카카오톡보다 훨씬 가볍습니다.

### 이미 준비되어 있는 것

- 137명 어머니·아버지·보호자 번호 (세 칸으로 나뉘어 있음)
- **형제자매 묶음 18가정** — 한 집에 같은 문자를 두 번 보내지 않게 묶을 수 있습니다
- 청구 대상 고르기(어머니/아버지) — 이미 인보이스에 있습니다
- 보낼 사건들 — 셔틀 출발·도착, 결석 접수, 인보이스 발행이 전부 시스템 안에 있습니다

---

## 2. 무엇과 연결하면 좋은가

### 1순위 — 결석·픽업 **접수 확인** 문자 🔴 가장 권합니다

학부모가 토들에 결석을 알렸을 때, **우리가 그것을 어떻게 읽었는지 되돌려 보냅니다.**

```
[GIA] 이연우 학생
9월 21일(월) ~ 23일(수) 결석으로 접수했습니다.
다르면 회신 주세요.
```

**왜 이것이 1순위인가.** 오늘 실제로 이런 일이 있었습니다.

> `이연우 9/21-23 일결석입니다` → 시스템이 **오늘 결석**으로 등록

고쳤지만, 같은 종류의 오독은 앞으로도 납니다. 자유 문장을 기계가 읽는 한 계속 납니다.
그런데 **접수 확인 문자가 나갔다면 학부모가 그 자리에서 알아챕니다.** "오늘이 아니라
21일부터인데요" 한 마디면 끝입니다.

지금은 학부모도 우리도 **틀린 줄을 모른 채 그날이 됩니다.**

- 오독을 사람이 아니라 **학부모가 잡아줍니다** — 가장 정확한 검증자입니다
- 학부모는 "내 연락이 처리됐나" 를 궁금해하지 않게 됩니다
- 하루 10건 안팎 → **월 2천원 정도.** 거의 공짜입니다

### 2순위 — 하원 셔틀 알림

GPS와 도착체크가 이미 돌고 있어서 보낼 거리가 준비돼 있습니다.

```
[GIA] 김서이 학생이 탄 27호가 학교를 출발했습니다. (16:05)
[GIA] 김서이 학생이 대치삼성아파트에서 하차했습니다. (16:32)
```

**다만 신중해야 합니다.** 한 번 보내기 시작하면 **안 오는 날 전화가 옵니다.**
GPS가 하루 끊기면 그날은 항의가 옵니다. 예전에 학부모 기능을 전면 제거하신 이력도
있고요. 한 개 노선으로 한 달 시범을 권합니다.

건수가 많아 비용도 여기서 대부분 발생합니다(100명 × 2건 × 20일 ≈ 월 4~8만원).
**하차 알림 하나만** 보내면 절반으로 줄고, 학부모가 실제로 궁금해하는 것도 그쪽입니다.

### 3순위 — 안 나타난 아이 (미탑승 경보)

하원 시각에 명단에 있는데 차에 안 탄 아이. **이건 사고로 이어질 수 있는 자리입니다.**

```
[GIA] 김서이 학생이 27호 탑승 명단에 있는데 아직 확인되지 않았습니다.
연락 부탁드립니다. (16:10)
```

건수가 거의 없고(하루 0~2건), 값어치는 가장 큽니다. 다만 **오작동하면 학부모를
놀라게 하므로**, 동승선생님이 체크를 늦게 한 경우와 진짜 미탑승을 가릴 수 있어야 합니다.
2순위 시범에서 체크 습관이 자리잡은 뒤에 켜는 것이 맞습니다.

### 4순위 — 인보이스 발행 안내

```
[GIA] 2026-1학기 교재비 143,000원 · 납부기한 9/20
자세히: https://gia-ops.vercel.app/i/xxxx
```

학기당 137건 → **1,400원.** 다만 올톡페이가 이미 카톡으로 청구서를 보내고 있다면
**중복**입니다. 그 경우 "발행됐다"는 짧은 안내만 보내거나, 아예 넣지 않는 편이 낫습니다.

### 5순위 — 교직원 쪽 (기사님·동승선생님)

기사님은 앱을 잘 안 봅니다. 그런데 문자는 봅니다.

```
[GIA] 27호 오늘 변경사항
· 결석 2명: 김서이, 이연우
· 오늘만 탑승 1명: 정하임 (김서이 정류장)
```

하원 30분 전에 한 번. 하루 8건(호차 수) → **월 1,600원.**
지금은 기사님이 링크를 열어야 알 수 있는데, 안 열면 모릅니다.

## 3. 비용

| 용도 | 월 건수 | 월 비용 |
|---|---|---|
| 결석·픽업 접수 확인 | 200 | 약 2,000원 |
| 미탑승 경보 | 20 | 약 200원 |
| 기사님 변경사항 요약 | 160 | 약 1,600원 |
| 인보이스 안내 | 137/학기 | 약 1,400원/학기 |
| **여기까지 합계** | | **월 4천원 이하** |
| (선택) 셔틀 출발·하차 알림 | 4,000 | 약 4~8만원 |

**셔틀 알림을 빼면 사실상 비용이 없습니다.** 90자를 넘으면 LMS(장문)가 되어
단가가 서너 배 오르므로, 문구는 짧게 씁니다.

---

## 4. 회신 문자를 받을 수 있는가

**제공사에 따라 됩니다.** 회신 전용 번호(1533·050 계열 등)를 받아 웹훅으로 넘겨주는
서비스가 있고, 별도 신청·월 이용료가 붙습니다.

다만 **지금 단계에서는 권하지 않습니다.** 받아봐야 결국 자유 문장이라, 토들에서 겪는
문제를 그대로 문자에서 또 겪습니다. 창구만 하나 더 늘어납니다.

회신은 **"다르면 회신 주세요"** 정도로 열어두고, 오면 사람이 읽는 편이 낫습니다.
접수 확인에 대한 회신은 어차피 하루 한두 건입니다.

## 5. 조심할 것

- **발신번호 등록 없이는 한 통도 못 보냅니다.** 법으로 막혀 있습니다. 먼저 하세요.
- **광고성 문구가 섞이면 안 됩니다.** 정보성만 보냅니다. `(광고)` 표기 의무, 야간 발송
  금지(21시~08시) 같은 규제는 광고성에만 걸리지만, 아예 섞지 않는 편이 안전합니다.
- **한 집에 두 번 보내지 않도록** 형제자매 묶음을 씁니다. 황씨네는 세 남매라
  같은 문자가 세 번 갈 수 있습니다.
- **보낸 기록을 반드시 남깁니다.** "안 왔다"는 말이 나왔을 때 확인할 방법이 없으면
  그 말을 반박할 수도, 인정할 수도 없습니다.
- 번호가 비어 있는 학생이 있으면 **조용히 빠집니다.** 발송 화면에 "연락처 없어 못 보낸
  N명"을 반드시 함께 보여줘야 합니다.

---

## 6. 권하는 순서

1. **발신번호 등록 + 대행사 계약** — 1~2일, 비용 거의 0
2. **결석·픽업 접수 확인 문자만** 켭니다 — 월 2천원. 오독을 학부모가 잡아줍니다
3. 2주 뒤 **기사님 변경사항 요약** 추가
4. **미탑승 경보** — 체크 습관이 자리잡은 뒤
5. **셔틀 출발·하차 알림은 마지막.** 한 개 노선 한 달 시범 뒤 결정
