# 「이 돈이 들어왔다」를 앱이 아는 방법

작성 2026-09-07 · 검토 대상: 올톡페이 API, 대안 경로, 국세청 현금영수증 연동

---

## 지금 상태

앱은 **「이 돈을 받아야 한다」까지만** 압니다.

```
학비외 항목 → 인보이스 발행 → 올톡페이 엑셀 내보내기 → (앱 밖) 청구 발송
                                                          ↓
                                          결제·입금  … 앱이 모르는 구간
                                                          ↓
                              수납 화면에 엑셀 올리기 → payments → 대사
```

가운데 구간이 비어 있어서, 미수금이 실제로 얼마인지는 **누군가 엑셀을 올린 시점까지만**
맞습니다. 그 사이에 들어온 돈은 앱에 없습니다.

---

## 1. 올톡페이 API — 공개된 것이 없습니다

올톡페이는 올댓페이(allthatpay.kr)의 청구 서비스입니다. 공식 사이트와 가입 안내에는
**Web 화면에서 수납·미수·통계를 관리한다**고만 되어 있고, 개발자 센터나 API 문서는
공개되어 있지 않습니다.

비교하자면 페이앱·토스페이먼츠·카카오페이는 모두 공개 개발자 문서와 연동 가이드가
있습니다. 올톡페이는 그 자리가 비어 있습니다.

**다음 할 일**: 올톡페이 고객센터에 직접 물어야 확실합니다. 물을 때 이렇게 물어야
답이 명확합니다.

> 가맹점 수납 내역을 프로그램에서 자동으로 가져갈 수 있는 방법이 있습니까?
> ① REST API ② 결제 완료 웹훅(Webhook) ③ 정산 파일 자동 전송(FTP·메일)
> 셋 중 하나라도 되면 어떤 절차가 필요한지 알려주세요.

②만 되어도 충분합니다. 결제가 끝나는 순간 우리 서버로 한 번 두드려 주면, 그 자리에서
`payments` 에 넣고 인보이스에 붙일 수 있습니다.

---

## 2. API가 안 될 때의 우회 경로 — 셋

### ㉮ 오픈뱅킹 계좌 조회 (권장)

금융결제원 오픈뱅킹으로 **학교 법인 계좌의 입금 내역**을 주기적으로 읽어옵니다.
계좌이체로 들어오는 돈은 이 길로 전부 잡힙니다. 올톡페이 카드 결제도 결국 정산금이
같은 계좌로 들어오므로, 총액 대사는 됩니다(다만 개인별로는 안 갈립니다).

- 필요한 것: 사업자 등록, 오픈뱅킹 이용기관 신청, 계좌 인증
- 걸리는 시간: 신청·심사에 몇 주
- 얻는 것: **사람이 아무것도 안 해도** 입금이 들어옵니다

### ㉯ 입금 알림 문자 자동 수집 (지금 바로 가능)

은행 입금 알림을 학교 구글챗 방으로 흘려보내고, 이미 만들어 둔 구글챗 미러링이 그것을
읽게 합니다. 출결 알림을 읽는 것과 **똑같은 구조**라 새로 만들 것이 거의 없습니다.

```
은행 앱 알림 → (전달) 구글챗 '입금알림' 방 → 미러링 → 금액·입금자명 파싱 → payments
```

- 필요한 것: 은행 알림을 그 방으로 보내는 설정 하나
- 걸리는 시간: 하루
- 한계: 문자 형식이 은행마다 다르고, 알림이 끊기면 조용히 멈춥니다
  (연동 상태 화면에 심박을 달아 «몇 시간째 조용함»을 띄우면 그 위험은 줄어듭니다)

### ㉰ 엑셀 업로드 자동화 (지금도 되는 것을 덜 아프게)

지금도 올톡페이 엑셀을 올려 대사하고 있습니다. 여기서 개선할 수 있는 것은
**「올릴 때가 됐다」고 알려주는 것**입니다 — 마지막 업로드가 3일 넘었으면 재무 화면
맨 위에 띄웁니다. 자동화는 아니지만, 잊어서 생기는 공백은 막습니다.

### 권할 순서

1. **㉯ 먼저** — 오늘 할 수 있고, 계좌이체 건이 바로 잡힙니다
2. **㉮ 병행 신청** — 몇 주 걸리므로 지금 신청을 걸어둡니다
3. 올톡페이 답이 오면 그것으로 갈아탑니다(웹훅이 있으면 그게 가장 정확합니다)

## 3. 국세청 현금영수증 자동 발행 — 필요한 것

지금은 **홈택스에서 손으로 발행**하고 앱에는 신청·발행 여부만 남깁니다
(`/finance/receipts`). 자동 발행으로 가려면 다음이 필요합니다.

| 항목 | 설명 |
|---|---|
| 사업자등록번호 | 학교 법인 명의 |
| 전자세금용 공동인증서 | 사업자 범용 또는 전자세금계산서용. 서버에 보관하고 갱신 관리 필요 |
| 홈택스 이용자 등록 | 현금영수증 가맹점 가입(이미 되어 있을 가능성이 높음 — 확인 필요) |
| 발행 방식 선택 | ① 국세청 직접 연동 ② ARS/단말기 ③ **전자세금계산서 사업자 대행**(팝빌·바로빌 등) |

**③을 권합니다.** 국세청과 직접 붙으려면 인증서를 서버가 들고 있어야 하고, 인증서
갱신·보관·유출 책임을 학교가 집니다. 대행 사업자를 쓰면 API 한 줄로 발행되고 인증서는
그쪽이 관리합니다. 비용은 건당 수십 원 수준입니다.

대행으로 갈 경우 준비물은 이것뿐입니다.

- 사업자등록증 사본
- 대행 사업자 가입 + API 키 발급
- 우리 쪽: `cash_receipts` 에 이미 필요한 칸이 다 있습니다
  (용도·식별번호·금액·승인번호) — **발행 함수만 갈아 끼우면 됩니다**

그래서 지금 화면을 «신청을 모으고 홈택스로 건너가는» 모양으로 만들어 둔 것입니다.
나중에 자동 발행이 붙어도 **화면과 자료는 그대로**이고, [발행함]을 누르던 자리가
[발행하기]로 바뀔 뿐입니다.

## 다음에 사람이 해야 할 일

1. 올톡페이 고객센터에 위 세 가지(API·웹훅·정산파일)를 물어보기
2. 은행 입금 알림을 구글챗 방으로 보낼 수 있는지 확인 (㉯를 만들지 정하는 갈림길)
3. 현금영수증 가맹점 가입 여부 확인 — 이미 되어 있으면 대행 붙이는 일만 남습니다
