# 학부모 앱 — 무엇을 넣어야 하는가

2026-09-03 · GIA 운영 시스템(gia-ops-web) 기준

---

## 먼저 짚을 것 두 가지

### ① 앱스토어 앱은 필요 없습니다

지금 기사님 설정링크(`/s/코드`)와 도착체크가 **로그인 없는 링크 + 홈 화면에 추가**로
돌고 있습니다. 학부모 앱도 같은 방식이면 됩니다.

| | 웹앱(홈 화면 추가) | 앱스토어 앱 |
|---|---|---|
| 설치 | 링크 눌러 "홈 화면에 추가" | 스토어 검색 → 설치 |
| 심사 | 없음 | 애플·구글 심사, 수정할 때마다 다시 |
| 고칠 때 | 배포하면 **즉시 전원 반영** | 학부모가 업데이트해야 반영 |
| 밀어서 알림(푸시) | **됩니다** (홈 화면에 추가한 경우) | 됩니다 |
| 만드는 비용 | 지금 앱에 화면 몇 개 추가 | 안드로이드·아이폰 따로, 스토어 등록 |

**아이폰은 홈 화면에 추가해야만 푸시가 갑니다.** 그래서 "홈 화면에 추가"를 안내하는
한 장짜리 그림이 설치 안내의 절반입니다. 이건 이미 도착체크에서 해보신 방식입니다.

### ② 학부모 기능은 한 번 전부 지웠던 적이 있습니다

기록에 남아 있습니다 — 학부모 위치 조회·알림을 만들었다가 **전면 제거**했습니다.
그때 왜 지웠는지가 이번 결정의 핵심입니다. 대개는 다음 셋 중 하나입니다.

- 알림이 안 가는 날 항의가 온다
- 위치를 보여주니 "왜 늦냐"는 전화가 더 늘었다
- 학부모가 볼 수 있게 되자 **실시간으로 정확할 의무**가 생겼다

**이 셋은 기능을 잘 만들어서 피할 수 있는 문제가 아닙니다.** 무엇을 보여주는 순간
그것이 틀렸을 때의 책임이 함께 생깁니다. 그래서 아래 목록은 "넣을 것"보다
**"넣지 말 것"** 이 더 중요합니다.

---

## 넣어야 할 것 — 우선순위대로

### 1순위 · 결석 · 픽업 · 동승 신청 (버튼으로)

**이것 하나만으로도 앱을 만들 이유가 됩니다.**

오늘 실제로 난 오류들입니다.

```
"이연우 9/21-23 일결석입니다"      → 오늘 결석으로 등록
"서이 셔틀에 하임이두 같이"        → 임하임인지 정하임인지 못 가림
"오늘 이예나 셔틀 안탑니다"        → 통째로 무시 (지금은 고쳤습니다)
```

원인이 전부 같습니다. **자유 문장을 기계가 읽어야 하기 때문**입니다. 표현이 새로 나올
때마다 또 틀립니다. 앱에서 버튼으로 받으면 **해석할 것이 남지 않습니다.**

```
오늘 우리 아이
─────────────────
김서이 (G4R) · 27호 · 대치삼성

[ 결석 ]  [ 픽업 ]  [ 셔틀 안 탐 ]  [ 다른 아이 차에 태워주세요 ]

→ 결석
  언제인가요?   [오늘] [내일] [기간 고르기]
→ 9/21 ~ 9/23
  ✓ 9월 21일(월)~23일(수) 결석으로 접수했습니다.
```

- 아이는 **내 아이 중에서만** 고릅니다 → 동명이인 문제가 아예 없습니다
- 날짜는 달력에서 고릅니다 → `9/21-23` 같은 오독이 없습니다
- 동승 요청도 **차 주인 아이를 목록에서** 고릅니다

### 2순위 · 접수 내역 (내가 낸 것을 학교가 어떻게 읽었나)

신청한 것들이 목록으로 남고, **학교가 어떻게 처리했는지**가 보입니다.

```
9/21~23 결석      접수됨 ✓
9/3  픽업 15:30   처리됨 ✓
9/2  동승 요청    확인 중 …
```

지금 학부모는 토들에 쓰고 나서 **처리됐는지 알 방법이 없습니다.** 그래서 한 번 더
쓰거나 전화합니다. 이 화면 하나가 그 전화를 없앱니다.

그리고 우리 쪽에도 이득이 큽니다 — 잘못 읽었을 때 **학부모가 잡아줍니다.**
이연우 건도 이 화면이 있었다면 그날 바로 정정됐습니다.

### 3순위 · 오늘 우리 아이 (첫 화면)

앱을 열면 바로 보이는 것. 글자 몇 줄이면 됩니다.

```
김서이 · 4학년 G4R
오늘  등원 ✓   하원  27호 · 대치삼성 16:30 예정
내일  수요일 — 블루웨일버스 16:30
```

형제자매가 있으면 **위에서 아이를 바꿉니다**(18가정이 해당됩니다).

### 4순위 · 셔틀 알림 (푸시) — 조심해서

GPS가 이미 돌고 있어서 만들 수는 있습니다. 다만 **보내기 시작하면 안 오는 날 전화가
옵니다.** 그래서 이렇게 좁힙니다.

- **하차 완료만** 보냅니다. "출발했습니다"는 학부모가 할 일이 없는 정보입니다
- 실시간 지도는 **넣지 않습니다** (아래 참고)
- 학부모가 **알림을 끌 수 있게** 합니다 — 원하지 않는 집이 반드시 있습니다

### 5순위 · 청구 · 납부 내역

인보이스 목록과 납부 상태. 지금 재무 화면에 있는 것을 학부모 쪽에서 읽기만 합니다.
"그거 냈는데요" 전화가 줄어듭니다.

### 6순위 · 가정통신문 · 학사일정

이미 문서함과 학사일정이 있습니다. 학부모용으로 **골라서** 내보내는 것만 만들면 됩니다.
전부 공개하면 안 됩니다.

## 넣지 말아야 할 것 — 여기가 더 중요합니다

### ✕ 채팅

토들이 이미 있습니다. 앱에도 채팅을 넣으면 **행정실이 볼 곳이 하나 더 늘어납니다.**
그리고 채팅창은 24시간 응대 기대를 만듭니다. 밤 11시에 온 메시지에 답이 없으면
그것이 불만이 됩니다.

**대신** "문의하기" 버튼은 토들로 연결하거나, 앱에서 남긴 글이 **지금 인박스 한 곳**으로
들어가게 합니다.

### ✕ 셔틀 실시간 위치 지도

가장 요청이 많고, 가장 후회하는 기능입니다.

- 차가 막히면 학부모가 **지도를 보며 전화합니다.** 문의가 줄지 않고 늘어납니다
- GPS가 끊긴 날 "차가 안 움직인다"는 연락이 옵니다
- 다른 집 아이의 정류장 순서가 노출됩니다

**하차 알림 한 줄**이 지도보다 낫습니다. 학부모가 알고 싶은 것은 위치가 아니라
**"내 아이가 내렸는가"** 입니다.

### ✕ 관찰기록 · 성적 전체 공개

담임 선생님이 **학부모가 볼 것을 의식하며** 쓰게 됩니다. 그 순간 기록은 무난해지고,
정작 필요한 관찰이 사라집니다. 학기말 리포트처럼 **정리해서 내보내는 것**만 공개합니다.

### ✕ 다른 아이 정보가 보이는 것

반 명단, 좌석표, 단체 사진 같은 것. 한 집이라도 문제 삼으면 되돌릴 수 없습니다.

## 만들기 전에 정해야 할 것

### ① 설치 안 한 집은 어떻게 하나

137가정 전부가 설치하지는 않습니다. 60%가 설치하면 **나머지 40%는 여전히 토들**입니다.
그러면 행정실은 두 곳을 봐야 합니다.

**답은 하나입니다 — 앱에서 온 것도 지금 인박스 한 곳으로 들어가야 합니다.** 화면에
"토들 / 앱" 표시만 다르고, 처리하는 자리는 같아야 합니다. 이걸 안 지키면 앱이
정확해질수록 행정실은 더 힘들어집니다.

### ② 누가 로그인하는가

- 어머니·아버지가 **각자** 쓸 수 있어야 합니다(지금 두 번호를 다 갖고 있습니다)
- 형제자매는 **한 계정에서 전환**합니다 (18가정)
- 비밀번호를 만들게 하면 절반이 못 들어옵니다. **전화번호 인증** 또는 학교가 발급한
  **일회용 링크**가 낫습니다

### ③ 응대 시간을 먼저 적어둡니다

앱 첫 화면에 적습니다. `평일 08:30~17:00 확인합니다. 급한 일은 전화 주세요.`
이 한 줄이 없으면 앱은 24시간 창구가 됩니다.

## 규모

| 무엇 | 규모 |
|---|---|
| 로그인(전화번호 인증) + 내 아이 연결 | 3일 |
| 오늘 우리 아이 화면 | 2일 |
| 결석·픽업·동승 신청 (버튼) | 3일 |
| 접수 내역 화면 | 1일 |
| 앱에서 온 신청을 지금 인박스에 합치기 | 1일 |
| 홈 화면 추가 안내 + 푸시 준비 | 2일 |
| **1차 합계** | **약 2주** |
| (나중) 청구·납부, 가정통신문, 셔틀 푸시 | 각 2~3일 |

새 서버도, 앱스토어 등록도 없습니다. 지금 앱에 화면을 더하는 일입니다.

## 권하는 순서

1. **한 반으로 시범**합니다 (G4R 11명 정도). 전교에 풀면 되돌릴 수 없습니다
2. 기능은 **1·2·3순위만** — 결석 신청 · 접수 내역 · 오늘 우리 아이
3. 한 달 뒤 **토들 문의가 실제로 줄었는지** 셉니다. 안 줄었으면 확대하지 않습니다
4. 셔틀 푸시는 **그다음**. 지도는 넣지 않습니다

시범을 한 반으로 하는 이유는, 예전에 학부모 기능을 전부 지운 적이 있기 때문입니다.
같은 일이 또 생기면 이번에는 **한 반만** 되돌리면 됩니다.
