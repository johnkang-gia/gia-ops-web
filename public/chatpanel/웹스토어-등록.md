# GIA 구글챗 패널 — 크롬 웹스토어(비공개 링크) 등록

웹페이지는 확장을 직접 설치할 수 없습니다. 크롬이 허용하는 «링크 한 번 → 설치 → 자동 갱신»은 **크롬 웹스토어**뿐이고,
그래서 한 번만 올려 두면 그 뒤로는 업무보드의 「웹스토어에서 설치」 단추 하나로 끝납니다.

## 1. 개발자 계정 (한 번, US$5)
1. https://chrome.google.com/webstore/devconsole 를 **johnkang@giamicro.com** 으로 엽니다.
2. 개발자 약관 동의 → 등록비 5달러(1회) 결제.
3. 「게시자 이름」: GIA Micro Lab

## 2. 올리기
1. 개발자 대시보드 › 「새 항목」 › 운영앱에서 받은 **`/chatpanel/gia-chat-panel-store.zip`** 업로드
   (폴더 없이 manifest.json 이 맨 위에 있는 쪽입니다. `gia-chat-panel.zip` 은 수동 설치용이라 올리면 거부됩니다).
2. 스토어 등록정보
   - 이름: GIA 구글챗 패널
   - 요약: GIA 운영앱에서 Google Chat을 크롬 사이드패널로 엽니다.
   - 설명: GIA 운영앱(gia-ops.vercel.app) 교직원용. 운영앱의 「구글챗」 손잡이를 누르면 chat.google.com 이 크롬 사이드패널에
     열립니다. 데이터 수집·전송 없음. 교직원 외에는 쓸모가 없습니다.
   - 카테고리: 생산성 › 업무 흐름 / 언어: 한국어
   - 아이콘 128px: zip 안의 icon.png 를 128×128 로 줄여 올리기 / 스크린샷 1280×800 한 장(사이드패널 열린 화면)
3. 개인정보 보호
   - 단일 목적: Google Chat 을 크롬 사이드패널에 띄움
   - 권한 사유
     - `sidePanel`: 사이드패널을 엽니다.
     - `declarativeNetRequest`: 사이드패널 안 iframe 에서 chat.google.com 을 열 수 있도록 응답 머리글(X-Frame-Options·CSP)을
       sub_frame 요청에서만 제거합니다. 요청 내용은 읽거나 바꾸지 않습니다.
     - 호스트 권한(google.com 계열): 위 머리글 제거 대상. gia-ops.vercel.app: 운영앱 손잡이의 «열어줘» 신호를 받는 content script.
   - 원격 코드: 사용 안 함(패널은 운영앱 페이지를 iframe 으로 띄울 뿐, 확장 안에서 외부 JS 를 실행하지 않음)
   - 데이터 사용: 수집하는 사용자 데이터 없음 → 전부 «아니오», 인증서 체크
4. 공개 범위: **「비공개 — 링크가 있는 사용자」** (Unlisted). 검색에 안 뜨고 링크로만 설치됩니다.
5. 「검토를 위해 제출」. 보통 1~3일. 승인 메일이 오면 항목 주소를 복사합니다:
   `https://chromewebstore.google.com/detail/<32자 id>`

## 3. 운영앱에 주소 넣기
Vercel › gia-ops › Settings › Environment Variables:
`NEXT_PUBLIC_CHAT_PANEL_STORE_URL = https://chromewebstore.google.com/detail/<id>` → Redeploy.
그 뒤로 업무보드 설치 안내는 「웹스토어에서 설치 ↗」 한 단추가 되고, 수동 6단계는 접힙니다.

## 4. 그 다음 갱신
- **패널 화면(도구 줄·안내)**: 운영앱 배포만으로 바뀝니다. 확장은 그대로.
- **확장 자체(manifest·background·bridge)**: `public/chatpanel/src/manifest.json` 의 version 을 올려 배포 → 개발자 대시보드에서
  새 `gia-chat-panel-store.zip` 을 「패키지 업로드」 → 제출. 승인되면 크롬이 각자 컴퓨터에서 **몇 시간 안에 스스로** 갱신합니다.
  급하면 chrome://extensions › 「업데이트」. 업무보드 손잡이 아래 「갱신」 표시는 깔린 버전과 배포 버전이 다를 때 뜹니다.
