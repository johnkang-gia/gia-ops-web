# 3. 부탁 ① — Google Workspace 권한

## 3-1. 무엇이 막혀 있나

구글챗의 출결 알림을 **실시간으로** 받아오려면 Google Cloud에 푸시 구독을 걸어야 합니다. 그 설정에 `gcp-service-agents@giamicro.com` 이라는 **그룹**을 하나 만들어야 하는데, 그룹 생성은 Workspace 관리자만 할 수 있습니다.

지금은 그 대신 **1분마다 확인하는 방식**으로 돌리고 있습니다. 동작은 하지만 최대 1분이 밀립니다. 하원 직전 "오늘 결석입니다" 연락은 1분이 아쉬운 상황이 있습니다.

## 3-2. 부탁드릴 것

두 가지 중 하나면 됩니다.

**(A) 그룹 하나만 만들어 주십사** — 5분이면 끝납니다.

```
관리 콘솔 → 디렉터리 → 그룹 → 그룹 만들기
이름: gcp-service-agents
이메일: gcp-service-agents@giamicro.com
소유자: johnkang@giamicro.com
```

**(B) 제 계정에 권한 일부를 위임** — 앞으로도 비슷한 설정이 생길 수 있어 이쪽이 낫습니다.

```
관리 콘솔 → 계정 → 관리자 역할 → 역할 만들기
필요한 권한: 그룹(생성·수정), Google Cloud 프로젝트 연결
※ 사용자 관리·비밀번호 재설정 권한은 넣지 않습니다.
```

> **왜 (B)를 권하는가**
> 앞으로 학부모 앱, 알림 발송, 문서 자동화 등에서 비슷한 설정이 계속 생깁니다. 그때마다
> 부이사장님 시간을 빌리는 것보다, 제한된 권한을 한 번 열어두는 편이 서로 편합니다.
> 계정·인사 정보에는 손대지 않는 범위로 한정할 수 있습니다.

# 4. 부탁 ② — 학부모 앱

## 4-1. 지금 방식의 문제

학부모가 토들에 "오늘 결석입니다"라고 쓰면, 이런 일이 벌어집니다.

```
① 크롬 확장 프로그램이 토들 화면을 긁어옵니다
   → 담당자 컴퓨터가 켜져 있어야 합니다. 꺼져 있으면 그날 연락을 통째로 놓칩니다.

② AI가 문장을 읽고 "결석인지 픽업인지" 판단합니다
   → 사람 말은 다양합니다. 100% 맞힐 수 없습니다.

③ 이름을 명부와 대조합니다
   → 여기서 가장 많이 틀립니다.
```

③이 실제로 얼마나 어려운지, 이번 주에 부딪힌 것들입니다.

| 학부모가 쓴 것 | 문제 |
|---|---|
| `Jay Kim` | 김재이가 세 명인데 영문명이 전부 같습니다 |
| `Jay Kim(190828)` | 생일을 적어주셔야 겨우 구별됩니다 |
| `dongha k` | 성이 잘려서 김동하와 한 글자도 안 맞습니다 |
| `Seohu K` | 같은 문제 |

**이건 프로그램을 잘 짜서 해결할 문제가 아닙니다.** 사람이 자유롭게 쓴 글을 기계가 해석하는 한, 오차는 남습니다. 지금은 규칙을 계속 다듬어 오차를 줄이고 있지만, 0이 되지는 않습니다.

## 4-2. 학부모 앱이 바꾸는 것

학부모가 **버튼을 누르면** 이 모든 단계가 사라집니다.

```
지금:  자유 문장 → 긁어오기 → AI 해석 → 이름 대조 → 사람 확인 → 반영
제안:  [우리 아이] [결석] [오늘]  →  즉시 반영
```

| | 지금 | 학부모 앱 |
|---|---|---|
| 학생 특정 | AI가 추측 | 로그인한 본인 자녀. 100% 확실 |
| 날짜 | 문장에서 해석 | 달력에서 선택 |
| 결석/픽업 | AI가 분류 | 버튼으로 선택 |
| 담당자 확인 | 매 건 필요 | 불필요 |
| 담당자 PC | 켜져 있어야 함 | 상관없음 |
| AI 비용 | 매 건 발생 | 없음 |

**부수 효과가 큽니다.**

- 행정실이 하루에 수십 건을 눈으로 확인하던 일이 사라집니다
- 크롬 확장 프로그램을 없앨 수 있습니다 (담당자 PC 의존 해소)
- 학부모는 셔틀 실시간 위치를 볼 수 있습니다 (이미 만들어 둔 기능)
- AI 호출이 줄어 비용도 내려갑니다

## 4-3. 만드는 방법 세 가지

### (가) 웹앱 — 링크로 여는 방식 ★ 권장

| | |
|---|---|
| 학부모 경험 | 문자로 받은 링크 → 홈 화면에 추가 → 앱처럼 씁니다 |
| 개발자 계정 | **불필요** |
| 심사 | 없음. 고치면 바로 반영 |
| 비용 | 추가 비용 없음 |
| 기간 | 2~3주 |
| 한계 | 푸시 알림이 iOS에서 제약이 있습니다 |

이미 기사님·동승선생님 화면을 이 방식으로 만들어 쓰고 있습니다. **검증된 방식입니다.**

### (나) 네이티브 앱 — 앱스토어 등록

| | |
|---|---|
| 학부모 경험 | 앱스토어에서 "GIA" 검색 → 설치 |
| 개발자 계정 | Apple 연 $99 · Google Play 최초 1회 $25 |
| 심사 | 최초 1~2주, 이후 수정할 때마다 며칠 |
| 비용 | 연 약 14만 원 + 개발 기간 증가 |
| 기간 | 6~10주 |
| 장점 | 푸시 알림이 확실합니다. 학부모가 "제대로 된 앱"으로 인식합니다 |

### (다) 웹앱 먼저, 네이티브는 나중에 ★★ 최종 권장

```
1단계 (지금~10월)   웹앱으로 만들어 시범 운영
                    → 실제로 얼마나 쓰시는지 확인
2단계 (11월~)       반응이 좋으면 네이티브로 감싸서 앱스토어 등록
                    → 웹앱 코드를 그대로 쓰므로 다시 만들지 않습니다
```

**이 순서를 권하는 이유는 하나입니다.** 학부모가 실제로 쓰실지 모르는 상태에서 개발자 계정과 심사 절차부터 밟으면, 안 쓰실 경우 그 비용이 전부 낭비됩니다. 웹앱은 안 쓰셔도 잃는 게 없습니다.

## 5-2. 앞으로 유료로 올려야 할 것

### (1) Supabase — 지금 그대로 두되, 지켜봐야 합니다

GPS 추적을 35대로 늘리면 위치 기록이 빠르게 쌓입니다.

```
기사님 폰 설정을 잘못 두면:  월 840만 건 → 1GB/월 → 1년이면 한도 초과
설정을 바로잡으면:           월 18만 건  → 22MB/월 → 여유 있음
```

이미 설정을 바로잡았고(30m 이동 시에만 전송), 오래된 기록을 매일 새벽에 지우는 자동화도 걸어두었습니다. **당장 올릴 필요는 없습니다.** 다만 35대 전면 운영 3개월 뒤 다시 보겠습니다.

### (3) 문자·알림 발송 — 새로 필요해질 수 있습니다

학부모에게 "차량이 곧 도착합니다"를 알리려면 두 가지 길이 있습니다.

| 방법 | 비용 | 비고 |
|---|---|---|
| 앱 푸시 알림 | 무료 | 앱을 설치하신 분만 |
| 문자(SMS) | 건당 약 20원 | 확실하지만 쌓이면 부담 |

**푸시를 기본으로, 문자는 긴급 상황에만** 쓰는 것을 제안드립니다. 하루 50건 기준 문자만 쓰면 월 3만 원, 연 36만 원입니다.

# 7. 위험과 대비

정직하게 말씀드릴 부분입니다.

## 7-1. 조용히 멈추는 실패

이번 주에 **GPS 추적이 3일 동안 죽어 있었는데 아무도 몰랐습니다.** 자동 실행 설정 하나가 빠져 있었고, 화면은 멀쩡해 보였습니다. 데이터만 안 들어왔을 뿐입니다.

같은 일이 다시 없도록 **연동 상태를 한 화면에서 보는 기능**을 만들었습니다. 무엇이 언제 마지막으로 돌았는지 초록불·빨간불로 표시됩니다. 다만 이런 종류의 실패는 앞으로도 생길 수 있고, **정기적으로 확인하는 습관이 함께 필요합니다.**

## 7-2. 한 사람에게 몰려 있는 것

지금 이 시스템은 제가 만들고 제가 고칩니다. 인수인계 문서와 코드 주석은 꼼꼼히 남기고 있지만, **제가 없을 때 급한 문제가 생기면 대응이 늦습니다.**

학부모 앱까지 가면 학부모가 직접 쓰는 시스템이 되므로, 이 부분은 미리 상의드려야 할 것 같습니다.

## 7-3. 학부모가 안 쓰실 가능성

앱을 만들어도 학부모가 여전히 토들로 연락하실 수 있습니다. 그래서 **토들 수집을 당장 없애지 않고 한 학기는 병행**할 계획입니다. 앱 사용률이 충분히 올라온 뒤에 정리하겠습니다.
