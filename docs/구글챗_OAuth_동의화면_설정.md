# 구글챗 OAuth 동의 화면 — 범위 추가하기

구글챗 방 목록·답장·사람 목록을 쓰려면 **권한(범위, scope)** 이 동의 화면에 적혀 있어야
합니다. 지금 앱이 쓰는 범위는 다섯 개입니다.

| 범위 | 하는 일 |
|---|---|
| `chat.spaces.readonly` | 방 목록 보기 |
| `chat.messages.readonly` | 메시지 읽기 |
| `chat.messages.create` | 답장 보내기 |
| `chat.memberships.readonly` | 방에 누가 있는지 보기(@멘션에 필요) |

---

## 먼저: 예전에 막혔던 것은 이 화면이 아닙니다

전에 구글챗 연동이 막혔던 곳은 **Pub/Sub 실시간 구독**이었습니다. 구글 시스템 계정을
Pub/Sub 주제의 게시자로 넣어야 했는데, 조직 정책(`constraints/iam.allowedPolicyMemberDomains`)이
외부 도메인 추가를 막았고 그건 **조직 정책 관리자**만 풀 수 있습니다.

그래서 Pub/Sub을 아예 걷어내고 **폴링**으로 바꿨습니다. 지금 하려는 일(동의 화면에 범위
추가)은 그것과 **다른 화면이고 다른 권한**입니다. 프로젝트 편집자 권한만 있으면 됩니다.

---

## 확인할 것 하나: 앱 유형이 «내부»인가

이게 가장 중요합니다.

- **내부(Internal)** — 우리 Workspace 조직 사람만 씁니다. 이 경우 **민감한 범위를 넣어도
  구글 검토가 필요 없습니다.** 범위를 추가하고 저장하면 바로 씁니다.
- **외부(External)** — 아무 구글 계정이나 쓸 수 있습니다. 이 경우 민감한 범위는 검토를
  받아야 하고, 그전까지는 「테스트 사용자」로 등록된 계정만 씁니다.

`chat.memberships.readonly` 는 구글 분류상 **민감한(sensitive) 범위**입니다. 그래서 앱 유형이
무엇이냐에 따라 할 일이 달라집니다. 우리 앱은 giamicro.com 계정만 쓰므로 **내부**가 맞습니다.

---

## 순서

1. <https://console.cloud.google.com/> 에 **giamicro.com 계정**으로 로그인합니다.
   개인 지메일로 들어가면 프로젝트가 안 보입니다.

2. 왼쪽 위에서 **구글챗 연동에 쓰는 프로젝트**를 고릅니다.
   어느 프로젝트인지 모르면, Vercel 환경변수 `GOOGLE_OAUTH_CLIENT_ID` 앞자리 숫자가
   프로젝트 번호입니다. 「API 및 서비스 → 사용자 인증 정보」에서 그 클라이언트 ID가 있는
   프로젝트가 맞는 곳입니다.

3. **API 및 서비스 → OAuth 동의 화면**(요즘은 「Google 인증 플랫폼」 아래에 있습니다).

4. **대상(Audience)** 을 봅니다.
   - 「내부」면 그대로 진행합니다.
   - 「외부」면 **내부로 바꿉니다.** 조직 소유 프로젝트여야 이 선택지가 보입니다.
     안 보이면 프로젝트가 조직 밖에 있는 것이고, 그때는 아래 「내부로 못 바꿀 때」를 보세요.

5. **데이터 액세스(Data access) → 범위 추가 또는 삭제**.

6. 아래 칸(「직접 범위 추가」)에 이 네 줄을 **한 줄씩** 붙여 넣고 [테이블에 추가]:

   ```
   https://www.googleapis.com/auth/chat.spaces.readonly
   https://www.googleapis.com/auth/chat.messages.readonly
   https://www.googleapis.com/auth/chat.messages.create
   https://www.googleapis.com/auth/chat.memberships.readonly
   ```

   목록에서 못 찾겠으면 검색창에 `chat.` 을 쳐서 걸러도 됩니다. **Google Chat API 가
   사용 설정돼 있어야** 목록에 뜹니다 - 안 보이면 「API 및 서비스 → 라이브러리」에서
   `Google Chat API` 를 켜고 돌아옵니다.

7. **업데이트 → 저장**.

8. 앱으로 돌아와 **연동 상태 → 구글챗 다시 연결**. 동의 화면에 늘어난 권한이 함께 뜹니다.
   여기서 **한 번 다시 승인해야** 예전 토큰이 새 권한을 갖습니다 - 이걸 안 하면 답장
   버튼과 @멘션이 「안 먹는」 것처럼만 보입니다.

9. 업무보드 인박스 아래 ⚙ → **[🔄 구글에서 방 목록 받기]** → **[모두 켜기]**.

---

## 내부로 못 바꿀 때

프로젝트가 조직 소유가 아니면 「내부」 선택지가 회색입니다. 두 가지 길이 있습니다.

- **프로젝트를 조직으로 옮깁니다.** 「IAM 및 관리자 → 설정 → 이동」. 조직 관리자 권한이
  필요합니다.
- **외부 + 테스트 사용자로 씁니다.** 「대상 → 테스트 사용자」에 연동에 쓰는 계정 하나를
  넣습니다. 검토 없이 바로 되지만, 테스트 모드의 **갱신 토큰은 7일이면 만료됩니다.**
  일주일마다 다시 연결해야 하므로 임시 방편입니다.

---

## 잘 안 될 때

| 증상 | 원인 | 할 일 |
|---|---|---|
| 「보내기 권한이 없습니다」 | 예전 토큰에 새 범위가 없음 | 연동 상태에서 다시 연결 |
| 「방 목록을 볼 권한이 없습니다」 | `chat.spaces.readonly` 누락 또는 재인증 안 함 | 6~8번 다시 |
| 동의 화면에 범위가 안 보임 | Google Chat API 미사용 설정 | 라이브러리에서 켜기 |
| 「확인되지 않은 앱」 경고 | 앱 유형이 외부 | 내부로 바꾸거나 테스트 사용자 등록 |
| 방 목록에 방이 안 뜸 | 연동 계정이 그 방의 멤버가 아님 | 그 계정을 방에 초대 |

방 목록은 **연동에 쓴 계정이 들어가 있는 방만** 보입니다. 계정이 안 들어간 방은 아무리
새로고침해도 안 뜹니다 - 그 방에 그 계정을 먼저 초대해야 합니다.
