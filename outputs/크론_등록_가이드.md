# 크론(자동 실행) 등록 가이드

크론이 하나도 없으면 앱은 **누가 화면을 열어볼 때만** 움직입니다. GPS는 계속 들어와도
"출발했다 / 도착했다"를 판단할 사람이 없어서 기록분석이 비어 있게 됩니다. 27호가 3일 내내
아무것도 안 잡힌 이유가 이것입니다.

---

## 먼저 알아둘 것 두 가지

**① 인증은 주소가 아니라 헤더입니다.**

제가 앞에서 `?token=...` 이라고 안내드렸는데 **틀렸습니다.** 코드는 이렇게 확인합니다:

```
Authorization: Bearer <CRON_SECRET>
```

주소에 토큰을 붙이면 401이 납니다. cron-job.org의 **Headers** 칸에 넣어야 합니다.
(주소에 비밀값을 넣지 않는 편이 더 안전하기도 합니다. 브라우저 기록·서버 로그에 남지 않습니다.)

**② `CRON_SECRET` 값은 Vercel에 있습니다.**

```
Vercel → gia-ops-web 프로젝트 → Settings → Environment Variables
→ CRON_SECRET 찾기 → 눈 아이콘(👁) 눌러서 값 확인 → 복사
```

없으면 아무 긴 문자열이나 만들어 넣고(예: 40자 랜덤) **Production·Preview 둘 다** 체크한 뒤
재배포하세요. 그 값을 아래 모든 크론에 씁니다.

## cron-job.org 등록 절차

### 1단계 · 계정

<https://cron-job.org> → 가입 → 로그인. 무료로 충분합니다.

### 2단계 · 첫 크론 만들기 (가장 급한 것)

오른쪽 위 **CREATE CRONJOB** 버튼.

**Common 탭**

| 칸 | 넣을 값 |
|---|---|
| Title | `셔틀 자동 도착·출발` |
| URL | `https://gia-ops.vercel.app/api/cron/shuttle-auto` |

**Schedule 탭**

`Every 1 minute(s)` 를 고릅니다. (또는 Custom → `* * * * *`)

> 1분마다가 부담스러워 보이지만, 앱 안에서 **평일 07~19시가 아니면 즉시 되돌아섭니다.**
> 나머지 시간에는 아무 일도 하지 않으니 비용이 늘지 않습니다.

**Advanced 탭** ← **여기가 중요합니다**

`Headers` 항목에서 **+** 를 눌러 한 줄 추가:

```
Key    : Authorization
Value  : Bearer 여기에CRON_SECRET값
```

`Bearer` 와 값 사이에 **띄어쓰기 한 칸**이 있어야 합니다.

**Request method** 는 `GET` 그대로 둡니다.

**SAVE** 를 누릅니다.

### 3단계 · 바로 확인

저장한 크론을 클릭 → **TEST RUN** 버튼.

```
{"ok":true, ...}                       → 잘 됩니다
{"ok":true,"skipped":"out_of_service_window"}  → 정상입니다. 지금이 운행 시간대가
                                          아닐 뿐이고, 인증은 통과했다는 뜻입니다.
{"error":"unauthorized"}               → Authorization 헤더를 다시 보세요.
                                          띄어쓰기·오타·값이 다른 경우입니다.
```

## 등록하면 안 되는 것

```
/api/cron/shuttle-auto-arrive     ← 없어졌습니다
/api/cron/shuttle-auto-depart     ← 없어졌습니다
```

이 둘은 `shuttle-auto` 하나로 합쳐졌습니다. 지금은 "여기로 옮겼습니다"만 답하고 아무 일도
하지 않습니다. 등록해도 해가 되진 않지만 낭비입니다.
