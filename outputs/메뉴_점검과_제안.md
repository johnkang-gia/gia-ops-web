# 메뉴 점검 결과와 제안

전체 라우트 60여 개와 사이드바 메뉴를 대조해 봤습니다. 먼저 **좋은 소식**부터.

## 메뉴 구조 자체는 정리가 잘 되어 있습니다

화면 60여 개 중 사이드바에 없는 것들은 대부분 상단탭(SectionTabs)으로 갈 수 있어서, **정말로 아무데서도 못 가는 화면은 두 개뿐**입니다. 5대 분류(업무·학교·셔틀·문서·주간기록)로 줄인 뒤 구조가 안정적입니다.

그래서 이 문서는 "메뉴를 다시 짜자"가 아니라 **끊긴 연결을 잇자**에 집중합니다.

---

## 1. 아무데서도 못 가는 화면 두 개 — 링크만 붙이면 됩니다

### `/print/driver-docs` · 기사님 안내문·동의서 인쇄

35대 기기를 나눠드릴 때 쓰는 인쇄물입니다. 만들어 뒀는데 **주소를 직접 쳐야만** 열립니다. 기기 배포를 곧 하실 텐데 그때 이 페이지를 못 찾으면 없는 것과 같습니다.

> 붙일 곳: 셔틀 → 링크·기기 화면 안 (기기 발급하는 자리 옆)

### `/weekly-report/subjects` · 과목별 관찰기록

주간 학생 관찰기록 메뉴에 반별·프린트·통계는 있는데 과목별만 빠져 있습니다.

> 붙일 곳: 주간 학생 관찰기록 서브메뉴

---

## 2. 같은 학생을 다루는데 화면끼리 안 이어집니다

이번 작업에서 계속 부딪힌 지점입니다. 데이터는 `student_id`로 이어 놨는데 **화면은 아직 안 이어져** 있습니다.

### ① 학생 프로필에 셔틀이 없습니다

`/students/[id]`를 열어도 이 아이가 **몇 호차를 타는지, 무슨 요일에 타는지** 안 나옵니다. 학부모 전화를 받으면 학생 조회 → 셔틀 → 노선·배정으로 세 번 옮겨 다녀야 합니다.

```
제안: 학생 프로필에 "셔틀" 칸 추가
      하원 4호(목) · 26-1호(월) · 정류장 반포자이 후문
      → 누르면 그 노선 화면으로
```

지난번 만든 `weekdays` 값이 여기서 바로 쓸 수 있습니다. 새로 만들 데이터가 없습니다.

### ② 문의사항에서 학생으로 못 갑니다

학부모 문의를 읽다가 "이 아이가 누구더라" 싶을 때, 이름은 이미 명부와 연결돼 있는데 **누를 수가 없습니다.**

```
제안: 문의 상세 창의 학생 이름을 /students/[id] 링크로
```

### ③ 하원체크표 ↔ 픽업 인박스

체크표 왼쪽 위젯에 오늘 픽업이 뜨는데, 원문을 보거나 새 픽업을 넣으려면 메뉴로 돌아가야 합니다.

```
제안: 위젯 제목 옆에 "픽업 인박스 ↗" 한 줄
```

---

## 3. 새로 생긴 관리 대상 — `정류장 미지정`

어제 하원 명단을 PDF 기준으로 다시 넣으면서, 예전 정류장을 물려받지 못한 아이들이 각 노선의 `정류장 미지정` 자리에 모였습니다. 지금은 **셔틀 화면을 하나하나 열어봐야** 몇 명이 거기 있는지 알 수 있습니다.

```
제안: 셔틀 개요에 "정류장 미지정 N명" 배지
      → 누르면 그 목록만 모아 보여주고, 거기서 정류장을 지정
```

이건 한 번 정리하면 끝나는 일이라, 정리를 마치면 배지가 사라집니다.

---

## 4. 연동 상태를 눈으로 볼 곳이 없습니다

이번에 27호 트래킹이 3일간 조용히 죽어 있었던 걸 **담당자가 눈치채서** 알았습니다. 진단하려면 제가 SQL을 만들어 드리고 담당자가 돌려야 했습니다.

지금 앱은 이런 것들에 의지합니다.

```
크론 12개          하나라도 죽으면 조용히 멈춥니다
토들 수집기        브라우저가 꺼져 있으면 안 돕니다
구글챗 미러
Traccar GPS        35대로 늘어납니다
```

이 중 무엇 하나가 멈춰도 **화면은 멀쩡해 보입니다.** 데이터가 안 들어올 뿐입니다. 그게 가장 위험합니다.

```
제안: 관리 → "연동 상태" 화면 하나
      항목               마지막 신호      상태
      셔틀 자동 크론     2분 전          🟢
      구글챗 수집        1분 전          🟢
      토들 수집기        3시간 전        🔴  ← 이런 게 보여야 합니다
      GPS 수신(27호)     8초 전          🟢
      GPS 저장량         이번 달 22MB    🟢
```

각 항목의 마지막 시각은 이미 DB에 다 있습니다. 읽어서 한 줄씩 보여주기만 하면 됩니다.

**이게 이 목록에서 가장 값어치 있는 항목이라고 봅니다.** 나머지는 편해지는 일이고, 이건 조용히 틀리는 것을 막는 일입니다.

## 5. 작은 것들

| 화면 | 제안 |
|---|---|
| 하원체크표 | 인쇄 버튼 옆에 "어제 것 보기" — 어제 누가 안 탔는지 확인하는 일이 잦습니다 |
| 학생 조회 | 검색창에서 Enter를 누르면 결과가 하나일 때 바로 그 학생 프로필로 |
| 노선·배정 | 정원 초과 노선을 목록에서 빨간 점으로 (지금은 열어봐야 압니다) |
| 교직원 | 담임 선생님 줄에 담당 반을 함께 |

---

## 순서 제안

```
1순위   연동 상태 화면            조용한 실패를 막습니다
2순위   학생 프로필 ↔ 셔틀        전화 응대 중 가장 자주 필요
3순위   정류장 미지정 정리 화면    지금 실제로 밀린 일
4순위   끊긴 링크 두 개           5분이면 끝납니다
5순위   나머지 작은 것들
```

어느 것부터 할지 말씀해 주세요. 4순위는 지금 바로 해도 됩니다.
